2026-08-03. It is the source for the Android launcher images under
`android/app/src/main/res/mipmap-*`.

The icon intentionally combines an API key, terminal prompt, and sparkle. It contains no text,
pricing, refund, or approval imagery. Keep the warm off-white and cobalt-blue palette aligned with
the Flutter Material 3 theme when producing future variants.
