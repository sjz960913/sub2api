# UI 界面生成提示词（简约版）

## 1. 已确认的产品规则

- Android MVP 底部菜单固定为：**聊天、协同、秘钥、我的**。
- `0.10 USD` 协同扣费完全由后台处理；App 不显示价格、扣费确认、账务状态或收费记录。
- 产品没有冻结、结算、退款流程，也没有 PC 审批中心、电脑确认或移动审批状态。
- “公告”位于“我的”页，点击后弹出公告列表。
- “我的”页提供“兑换”和“充值”；充值用系统外部浏览器打开 `https://pay.ldxp.cn/shop/codecodeai`。
- “秘钥”页以 API Key 卡片列表呈现；可修改分组，并选择唯一的当前聊天 Key。

## 2. 视觉参考与设计系统

```text
为 Sub2API Mobile 设计可直接由 Flutter 实现的高保真 Android UI。

视觉气质：简洁、安静、可靠，参考用户提供界面的留白和信息密度。使用暖白背景 #F8F7F3、白色卡片、深色正文、Cobalt Blue #304FFE 主色、极浅薰衣草色图标底块。卡片只使用 1px 浅灰边框与很轻的阴影，不使用渐变。

页面标题使用 28sp 左对齐粗体；正文使用 Noto Sans SC / Roboto 14–16sp；Key、用量和技术标识使用 JetBrains Mono。主按钮高 48px、圆角 10–12px；卡片圆角 14px；触控目标至少 44x44。

底部菜单是悬浮式白色圆角容器，四项等宽，顺序固定为“聊天、协同、秘钥、我的”。每项使用线性图标与文字，选中项为蓝色，未选中为深灰；任何页面都不能出现第五个主菜单。

不要：费用条、0.10 USD、退款、冻结/结算、审批、电脑确认、巨型插画、3D 机器人、霓虹、玻璃拟态、大渐变、完整 API Key、JWT、真实邮箱或完整本机路径。

移动 Frame 390x844；Auto Layout；8pt spacing grid；Light Mode 优先，组件必须覆盖 loading/empty/error/offline/disabled。
```

## 4. 页面提示词

### M-01 站点与登录

```text
设计两个 390x844 Android artboard：站点连接、邮箱密码登录。使用既定暖白简约设计系统。

站点页：标题“连接 Sub2API”；站点地址输入框；“检测连接”；成功状态显示站点名与 HTTPS；主按钮“继续”。
登录页：站点域名、HTTPS 图标、邮箱、密码、忘记密码、主按钮“登录”；小字“登录凭证仅发送到当前站点”。

不放底部菜单；不使用装饰插画；错误就地显示。
```

### M-02 聊天首页

```text
设计“聊天”主菜单页，390x844。

顶部标题“聊天”。标题下方放当前秘钥卡：标签“当前秘钥”，名称“Mobile Chat”，分组“OpenAI · 默认分组”，脱敏值“sk-••••8H2Q”，右侧文字按钮“切换”。

主体是简洁的最近对话卡片列表，显示标题、单行预览和时间；右下角蓝色新建对话按钮。当前 Key 不可用时显示空状态“请先在秘钥页选择可用秘钥”。

底部菜单“聊天、协同、秘钥、我的”，聊天选中。
```

### M-03 普通聊天与图片生成

```text
设计普通聊天详情与 GPT Image 设置页。

聊天详情顶部显示标题和当前 Key“Mobile Chat · sk-••••8H2Q”，提供“切换”。消息区使用开放式助手 Markdown、用户轻量气泡、代码块复制。底部是多行输入与发送。

图片设置页保持同一风格，包含 prompt、GPT Image 模型、参考图、尺寸、质量、数量和“开始生成”。页面不放置协同固定费用、扣费提示或价格确认。
```

### M-04 协同首页

```text
设计“协同”主菜单页，390x844，尽量简约。

顶部标题“协同”。一张紧凑 PC 卡显示“Workstation”“Linux · 在线”和“查看会话”。下面标题“最近 Codex 会话”，显示 2–3 张简单会话卡：标题、更新时间、短预览、状态“可继续”。页面只有一个明显主操作“同步会话”。

无设备时只显示三步文字：安装 PC 工具、登录同一站点、保持在线。不得出现费用、退款、审批或电脑确认。

底部菜单中协同选中。
```

### M-05 协同会话列表与详情

```text
设计两个 390x844 artboard：会话查询列表、Codex 会话详情。

列表页：设备“Workstation · 在线”、搜索框、操作“同步会话”、会话卡标题/预览/时间/“可继续”。离线时使用小型错误条和“重试”。

详情页：标题、设备在线状态、同步图标；时间线只突出用户任务和 Codex 最终回复。命令与文件修改压缩为默认折叠行，例如“命令执行 · 已完成”“修改 3 个文件”。底部输入“继续发送任务”。

不显示终端墙、账务状态、价格、二次确认、退款时间线、审批横幅或 PC 确认。
```

### M-06 秘钥卡片列表

```text
设计“秘钥”主菜单页，390x844。

以纵向卡片列出 API Key。每张卡必须包含：Key 名称、脱敏 Key、状态、分组下拉栏、本月用量、当前聊天选择。

第一张示例：名称“Mobile Chat”，Key“sk-••••8H2Q”，分组下拉“OpenAI 默认”，用量“$3.26”，蓝色选中按钮“当前聊天使用”。
第二张示例：名称“Image Lab”，Key“sk-••••1K9M”，分组“OpenAI 图片”，用量“$1.08”，描边按钮“设为当前”。

分组更新中只禁用当前卡；失败时卡内显示错误和重试。切换当前 Key 后 Toast“已切换聊天秘钥”。底部菜单中秘钥选中。
```

### M-07 我的

```text
设计“我的”主菜单页，390x844，参考提供图片的个人中心布局。

顶部标题“我的”。资料卡居中显示头像字母 A、脱敏邮箱“admin@••••.com”和角色“管理员”。下方菜单依次为“兑换”“充值”“公告”“设置”“关于”“退出登录”；公告右侧显示未读 badge“3”。每行有浅色图标底块和 chevron。

管理员可在设置上方额外显示“管理控制台”；普通用户完全隐藏。底部菜单中我的选中。
```

### M-08 兑换、充值与公告

```text
基于“我的”页设计三种交互状态。

兑换：居中 Dialog，标题“兑换码”，输入框“请输入兑换码”，按钮“取消”“兑换”；提交中禁用按钮，成功后 Toast 并刷新余额。

充值：点击“充值”直接调用系统外部浏览器打开 https://pay.ldxp.cn/shop/codecodeai。App 内不做 WebView、充值表单或支付结果伪造；若无法打开，显示错误 Toast“无法打开充值页面”。

公告：从底部弹出约 70% 高的 Bottom Sheet，标题“公告”，筛选“全部/未读”；列表显示未读蓝点、标题、摘要和时间。点击条目进入可滚动详情，按钮“我知道了”。
```

## 5. PC Companion 简约界面

桌面左侧导航固定为：概览、会话、实时任务、设置。不存在“审批”入口。

### P-01 概览

```text
设计 1440x900 Codex PC Companion 概览页。紧凑侧栏，主区显示设备名、站点、连接状态、可发现会话数、运行任务与最近事件。只展示脱敏 ID 和状态，不显示移动端费用或账务数据。
```

### P-02 会话与实时任务

```text
设计简洁桌面会话列表与实时任务页。会话列表提供搜索、目录筛选和“可继续/外部占用/只读”；详情时间线默认折叠命令和文件摘要。实时任务展示 queued/running/completed/failed。

没有审批队列、允许/拒绝按钮或手机等待电脑确认。若 app-server 请求审批，任务显示普通失败原因“当前安全策略不允许该操作”。
```

### P-03 设置

```text
设计账号与站点、设备名、开机启动、托盘、Codex CLI、同步隐私、日志和诊断设置。安全策略显示为只读的本机配置摘要；不得提供一键“允许所有”或 danger full access。
```

## 6. 通用负面提示词

不要：0.10 USD、费用提示、价格确认、收费记录、冻结、结算、退款、审批、电脑确认、Allow All、强制接管、五项底栏、公告独立主菜单、完整 API Key、JWT、真实邮箱密码、完整本机路径、营销落地页、3D 机器人、霓虹、玻璃拟态、巨大渐变、不可实现的装饰布局。

## 7. UI 验收

- 所有 App 主页面底栏只有“聊天、协同、秘钥、我的”。
- 当前聊天 Key 在聊天页可见，在秘钥页可切换；分组下拉与当前选择是两个独立操作。
- App 任意界面都不出现协同金额、退款或审批状态。
- “公告”只从“我的”打开；“充值”只调用外部浏览器的固定 HTTPS URL。
- 协同页以设备、会话和同步为主，默认折叠技术细节。
- 所有 Key、邮箱、ID 和路径都使用脱敏假数据。
